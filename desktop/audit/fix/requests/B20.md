# B20 shared-change requests

## desktop/src/lib/api/leads.ts

- `CreateLeadRequest.assignedTo` / `UpdateLeadRequest.assignedTo` should be `string | null` (backend treats `null` as "leave unassigned"). B20 sends `null` through a local cast.
- `leadsApi.list` params should include `priority?: string` (the server filters on it; B20 passes it through a local cast).

## desktop/src/lib/utils.ts

- No change needed. `getInitials` takes the first two words, which is correct for "Demo Admin"; the tasks pages use a local `initialsOf` (first + last name) for names with 3+ words.
