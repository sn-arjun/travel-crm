# B23 shared-change requests

1. CurrencyInput (components/ui/currency-input.tsx): on focus it replaces the displayed value, so Playwright `fill()` on an already-formatted value appends instead of replacing ("3,500" + 4200). Suggest select-all on focus. Worked around in the e2e spec by focusing first.
2. useApiQuery (hooks/use-api.ts) nulls `data` while refetching, so it cannot back silent polling. Trip detail uses local state instead; a `silent` refetch option would let pages share it.
