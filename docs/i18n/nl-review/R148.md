# R148 machine-made Dutch for review

Public booking page for a departure (customers see these texts when the agency's language is Dutch or they switch to Dutch) and the staff card and invoice action on the departure page. Files: `desktop/src/messages/nl/booking.json` and `desktop/src/messages/nl/departures.json` (keys `departures.publicPage.*` and `departures.invoice.*`). The server texts of the public booking API are in `backend/src/i18n/nl.ts` under `public.booking.*` and `booking.invoice.*`.
