# R151 machine-made Dutch for review

Chat widget contact capture. Desktop texts are in `desktop/src/messages/nl/chatbot.json`; the widget form's default wording (shown to website visitors of a Dutch agency) is in `backend/src/i18n/nl.ts` under `chatCapture.*`.

| Key | Dutch |
|---|---|
| `chatbot.capture.tab` | Contactgegevens |
| `chatbot.capture.title` | Vraag om contactgegevens |
| `chatbot.capture.description` | Laat de chat op uw website bezoekers om hun gegevens vragen, zodat een chat een lead kan worden zonder dat medewerkers ernaar vragen. |
| `chatbot.capture.mode` | Wanneer vragen |
| `chatbot.capture.mode.off` | Nooit (de chat werkt zoals eerst) |
| `chatbot.capture.mode.before_chat` | Voordat de chat begint |
| `chatbot.capture.mode.after_first_reply` | Na het eerste antwoord |
| `chatbot.capture.mode.before_handoff` | Voordat het gesprek naar een medewerker gaat |
| `chatbot.capture.offHint` | Er wordt niets gevraagd zolang dit op Nooit staat. |
| `chatbot.capture.fields` | Gegevens die u vraagt |
| `chatbot.capture.state.hidden` | Niet gevraagd |
| `chatbot.capture.requireOneOf` | Minstens e-mail of telefoon |
| `chatbot.capture.requireOneOfHint` | De bezoeker moet een e-mailadres of telefoonnummer geven, zodat u hem of haar kunt bereiken. |
| `chatbot.capture.consentText` | Toestemmingstekst |
| `chatbot.capture.consentHint` | Wordt getoond naast het vakje dat de bezoeker moet aanvinken. Laat leeg voor de standaardtekst in uw taal. |
| `chatbot.capture.marketingOptIn` | Bied een vakje voor marketingberichten aan |
| `chatbot.capture.marketingHint` | Een apart, optioneel vakje. Marketing is alleen toegestaan als de bezoeker het aanvinkt. |
| `chatbot.capture.autoCreateLead` | Maak automatisch een lead aan |
| `chatbot.capture.autoCreateLeadHint` | Zodra de gegevens binnenkomen worden een contact en een lead aangemaakt, zonder klik. |
| `chatbot.visitor.empty` | De bezoeker heeft nog geen naam, telefoonnummer of e-mailadres gedeeld. |
| `chatbot.visitor.consentGiven` | Akkoord om gecontacteerd te worden op {date}. |
| `chatbot.visitor.marketingYes` | Marketingberichten toegestaan. |
| `chatbot.visitor.marketingNo` | Geen toestemming voor marketingberichten. |
| `chatCapture.title` (backend) | Hoe kunnen we u bereiken? |
| `chatCapture.consent` (backend) | Ik ga ermee akkoord dat jullie contact met mij opnemen over mijn aanvraag. |
| `chatCapture.marketing` (backend) | Stuur mij aanbiedingen en nieuws (optioneel) |
| `chatCapture.submit` / `skip` (backend) | Doorgaan / Nu niet |
| `chatCapture.error` (backend) | Controleer uw gegevens en probeer het opnieuw. |
